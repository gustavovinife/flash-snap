# Flash Snap Mobile

Expo (SDK 57) app for iOS and Android. It uses the same Supabase backend as the desktop app, so decks, cards and review progress are shared between devices.

## Features

- Email/password and Google sign-in
- Decks and cards: create, edit, delete, search
- Spaced-repetition reviews (same SM-2 scheduling as desktop) with pronunciation for language decks
- Deck stats, ready-made templates, daily review reminder
- English and Brazilian Portuguese, light and dark mode

## Getting started

```bash
cp .env.example .env   # fill in the Supabase values
yarn dev:mobile        # from the repo root, then scan the QR code with Expo Go
```

## Structure

- `app/` – screens (expo-router file-based routes)
- `src/components/` – shared UI
- `src/hooks/` – React Query data hooks (decks, cards, subscription)
- `src/lib/` – Supabase client, SM-2 scheduling, reports, reminders, templates
- `src/i18n/` – translations

Entities, scheduling, reports, templates and AI types come from `@flash-snap/shared` (`packages/shared`).

## AI deck generation

Decks are generated by the `generate-deck` Supabase Edge Function (`packages/desktop/supabase/functions/generate-deck`), which keeps the OpenAI key on the server. To deploy it:

```bash
brew install supabase/tap/supabase
supabase login
cd packages/desktop
supabase secrets set OPENAI_API_KEY=sk-...
supabase functions deploy generate-deck
```

## Google sign-in

Add `flashsnap://auth-callback` (and your Expo Go URL, e.g. `exp://192.168.x.x:8081/--/auth-callback`, while developing) to the allowed redirect URLs in Supabase → Authentication → URL Configuration.
